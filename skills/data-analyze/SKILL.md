# 数据分析

把表格与接口数据算清楚。

## 做什么

**程序算数，模型解读。** 所有数字都由这份能力算出来，不许模型心算——模型会把两行数成三行。

支持四种操作：

- `describe`：整份数据的画像。每列的类型、有效值、缺失数、不同取值个数；数值列还给出最小/最大/平均/中位/标准差/四分位。
- `groupby`：按列分组，组内对每个数值列给出求和、均值、最小、最大。
- `filter`：按条件筛行，给出命中行数与命中行。
- `top`：按列排序取前 N。

## 输入

- `source`：数据。可以是数据本身，也可以是一个地址（地址会先取回来再算）；留空则接着上一步的产出算。
- `format`：`auto` / `json` / `csv` / `tsv`，默认自动判断。
- `op`：`describe` / `groupby` / `filter` / `top`，默认 `describe`。
- `groupBy`：分组列，多列用逗号隔开。
- `column`：筛选或排序作用的列。
- `condition`：筛选的比较方式（`eq` `ne` `gt` `gte` `lt` `lte` `contains`）；`top` 时用 `asc` / `desc`。
- `value`：筛选的比较值。
- `limit`：`top` 取前几条、`filter` 返回多少行。

## 返回

- `summary`：行数、列数，或命中的行数。
- `output`：算好的数字，写成人能读的样子。
- `data`：结构化结果（画像、分组汇总、命中行）。

## 怎么用

1. 数据在远端就先 `web.fetch` 取回来。
2. 调这份能力算：先 `describe` 看清有哪些列、有没有缺失，再按需要 `groupby` / `filter` / `top`。
3. 要算的不止一个维度，就多调几次——上一次的产出可以直接喂给下一次。
4. 汇报时给的是算好的数字，加上你的解读。

## 边界

- 列名要写对：写错了会直接报「没有这一列」，并列出可用的列名。
- 数值列会跳过空值；空值计入「缺失」。
- 非数值列不参与求和与均值，只统计个数与取值分布。
