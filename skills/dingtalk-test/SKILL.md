# 钉钉连通性测试

按当前已保存的配置发一条测试消息，验证通道是否通畅。

## 做什么

不必先改配置再保存——这里用的是已经存好的那一份，测不过就去管理后台里改，改完再测一次。

## 输入

- 无参数

## 返回

是否发送成功与失败原因。

## 怎么用

填好参数、跑一次，拿到结果就结束。

## 权限

仅管理员可用。

## 边界

- 不进「一句话任务」：要么它会写数据（跑错就是错数据），要么它没有终点（任务成败不该取决于设备什么时候发数据）。这两种都请手动跑。
