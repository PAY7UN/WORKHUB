# 智能问答

基于检索到的资料回答一个问题，流式返回正文与引用。

## 做什么

先召回资料再回答，引用的是召回时真正用上的那几篇，所以每条结论都能追回原文核对。检索范围受管理员配置限制，不会越过它。

## 输入

- `question`：问题（必填）

## 返回

回答正文（流式），以及本次引用的资料列表。

## 怎么用

填好参数、跑一次，拿到结果就结束。

## 边界

- 可以进「一句话任务」：由 agent 依据需求自动挑起并串联。
