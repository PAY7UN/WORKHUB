# 文档清单

列出当前身份可见的全部文档（只含元数据，不含正文）。

## 做什么

正文存在仓库目录的文件里，列清单时不会把整库读一遍。要正文得再用「取正文」那条路。

## 输入

- 无参数

## 返回

文档元数据数组：名称、类型、归属仓库、更新时间。

## 怎么用

填好参数、跑一次，拿到结果就结束。

## 边界

- 可以进「一句话任务」：由 agent 依据需求自动挑起并串联。
