# 提醒清单

列出全部提醒及其状态、触发时间与推送结果。

## 做什么

提醒到点会推到钉钉，过程与结果都留痕：失败过一次的原因也在里面。

## 输入

- 无参数

## 返回

提醒数组：标题、触发时间、重复规则、状态、已推送次数、最近错误。

## 怎么用

填好参数、跑一次，拿到结果就结束。

## 权限

仅管理员可用。

## 边界

- 可以进「一句话任务」：由 agent 依据需求自动挑起并串联。
