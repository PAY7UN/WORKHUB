# 新建提醒

排一条提醒，到点推到钉钉。

## 做什么

时间按本地时区填写；重复规则可设为每天、每周或每月。提醒可以关联一篇文档，推送消息里会带上文档名。

## 输入

- `title`：标题（必填）
- `remindAt`：触发时间（必填）
- `content`：内容（选填）

## 返回

新建好的提醒记录。

## 怎么用

填好参数、跑一次，拿到结果就结束。

## 权限

仅管理员可用。

## 边界

- 不进「一句话任务」：要么它会写数据（跑错就是错数据），要么它没有终点（任务成败不该取决于设备什么时候发数据）。这两种都请手动跑。
