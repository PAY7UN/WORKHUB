# 我的能力

一句话说清这份能力干什么（界面上显示的那句）。

## 做什么

写清楚它到底做了什么、动了哪些数据。
写给人看，也写给模型看：模型读不懂「大概就是查一下」这种话。

## 输入

- `keyword`：要传什么（必填/选填，字段名与 skill.json 里的 key 对上）。

## 返回

写清楚返回什么，模型才知道拿到结果后该干什么。

## 怎么用

填好参数、跑一次，拿到结果就结束。

## 边界

- 什么时候**不该**用它。这一段比「做什么」更能防止模型乱用。
