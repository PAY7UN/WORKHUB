# 全文检索

按关键词搜文档标题与正文，返回带片段的命中列表。

## 做什么

走 SQLite FTS5 全文索引，中文按二元组切分。命中会带出所在目录与正文片段，用来回答「哪篇文档里写过这件事」。

## 输入

- `q`：关键词（必填）。空词等于清空结果，不会返回任何命中。

## 返回

命中列表：文档名、所在目录路径、命中片段、命中位置（标题或正文）。

## 怎么用

填好参数、跑一次，拿到结果就结束。

## 边界

- 可以进「一句话任务」：由 agent 依据需求自动挑起并串联。
