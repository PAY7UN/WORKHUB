# 附件清单

列出某篇文档挂着的附件及其可检索状态。

## 做什么

附件与文档正文是同一种东西，只是来源不同：抽出了纯文本的附件也能进检索。textStatus 会告诉你这份附件能不能被搜到。

## 输入

- `docId`：文档 id（必填）

## 返回

附件数组：文件名、大小、类型、是否已抽出可检索文本。

## 怎么用

填好参数、跑一次，拿到结果就结束。

## 边界

- 可以进「一句话任务」：由 agent 依据需求自动挑起并串联。
