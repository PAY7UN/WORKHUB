# 文档润色

按指令重写一段正文，返回润色后的全文。

## 做什么

润色是对全文的重写，耗时可达数十秒，故在服务端后台推进：本工具会等它跑完再把结果交回来，任务本身不会因为刷新页面而丢失。

## 输入

- `content`：原文（必填）
- `instruction`：润色要求（必填）

## 返回

润色后的全文，以及相对原文的改动行数。

## 怎么用

填好参数、跑一次，拿到结果就结束。

## 权限

仅管理员可用。

## 边界

- 不进「一句话任务」：要么它会写数据（跑错就是错数据），要么它没有终点（任务成败不该取决于设备什么时候发数据）。这两种都请手动跑。
