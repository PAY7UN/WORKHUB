# 申请访问加密文档

对加密文档提交访问申请，等管理员审批。

## 做什么

加密文档的正文只以密文落库，任何人（包括管理员）想看都得走这条申请路。审批通过后凭授权免密打开。

## 输入

- `docId`：文档 id（必填）
- `reason`：申请理由（必填）

## 返回

申请单 id 与当前状态（在审 / 已批准 / 已拒绝）。

## 怎么用

填好参数、跑一次，拿到结果就结束。

## 边界

- 不进「一句话任务」：要么它会写数据（跑错就是错数据），要么它没有终点（任务成败不该取决于设备什么时候发数据）。这两种都请手动跑。
