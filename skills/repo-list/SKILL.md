# 仓库清单

列出全部仓库（项目）及各自的文档数、附件数与占用空间。

## 做什么

仓库是「一个项目」的容器：文档归属、检索范围、上传规则都按仓库切分。看这条就知道资料现在分成几摊、每摊有多大盘。

## 输入

- 无参数

## 返回

仓库数组 + 统计数组（文档数、附件数、占用字节）。

## 怎么用

填好参数、跑一次，拿到结果就结束。

## 边界

- 可以进「一句话任务」：由 agent 依据需求自动挑起并串联。
